# 个人项目工作室 · 作品集站点

本目录收录展示 `E:\harness` 工作区项目的**两个站点版本**，各自独立、互不影响。

| 目录 | 版本 | 形态 | 页面数 |
|---|---|---|---|
| `web/` | 单页版（2026-09 发布） | 一个长页 + 锚点导航 | 1 |
| `site/` | 多页版（2026-10-05 新增） | 首页 / 总览 / 13 个详情页 / 工作流 / 关于 | 18 |

两者均为**零依赖**：不引用任何 CDN 或外部字体，拷到任何地方双击 `index.html` 就能打开。

## 一、多页版 `site/`（2026-10-05）

覆盖工作区全部 **13 个** 项目（编号 `01`、`03`–`09`、`11`–`15`(编号 02 未列入展示)），每项目一个独立详情页。

```
site/
├── index.html          # 首页：hero、精选四个、五步工作流、14 项目一览
├── projects/index.html # 总览：技术栈分布 + 形态与依赖对照表
├── projects/*.html     # 13 个详情页（由 build-pages.js 生成，勿手改）
├── how-it-works.html   # 工作流：05 五步全链路 + 11 算力链路
├── about.html          # 素材标注规则、数字出处
├── projects.js         # 唯一数据源
├── app.js              # 组件渲染 + 程序化示意图
├── styles.css          # 设计令牌、深色模式、响应式
├── build-pages.js      # node build-pages.js → 重新生成 13 个详情页
├── verify-site.js      # Playwright 渲染验证
└── screenshots/        # 实拍截图（14 张 + 1 动图）
```

**架构**：`projects.js` 是唯一数据源 → `build-pages.js` 生成详情页 → 首页与总览页读同一份数据。
改内容只改数据层再跑生成器，避免文案与截图路径多处漂移。

**素材分三类，逐张标注**：实拍截图（4 个项目，绿标）/ 界面示意（9 个项目，橙标，按 README 描述程序化绘制）/ 结构示意（09，可交互 HTML 源文件）。页面上不把示意图冒充截图。

```bash
cd site
python -m http.server 8000     # 打开 http://localhost:8000
node build-pages.js            # 改完 projects.js 后重新生成详情页
```

详见 [`site/README.md`](site/README.md)。

## 二、单页版 `web/`（2026-09）

一个自包含的单页静态站点，把散在各处的自用桌面工具、审查报告与归档习惯收拢成一个能对外讲的页面。

```
web/
├── index.html   # 页面结构（519 行）
├── styles.css   # 全部样式（1109 行，含深色模式与响应式）
└── app.js       # 交互脚本（93 行）
```

### 页面结构

| 锚点 | 标题 | 内容 |
|---|---|---|
| `#works` | 八个项目，五套技术栈 | 各项目的定位、技术栈与当前状态 |
| `#practice` | 六条能对账的工程约定 | 依赖单向、纯函数可测、数据本地优先、变更必留档等 |
| `#archive` | 归档与可追溯 | 每次改动都留出处的工作区归档方式 |
| `#outputs` | 作品之外 | 报告、文档等副产物 |
| `#about` | 关于这些项目 | 项目来源与边界说明 |

> 此版只覆盖当时的 8 个项目，是 2026-09-24 的快照。后续新增的项目（05 之后的部分、11–15）只在 `site/` 里有。

```bash
cd web
python -m http.server 8000
# 打开 http://localhost:8000
```

或直接双击 `web/index.html`。

## 设计约定（两版共同）

- 语义化 HTML + 原生 CSS 变量做主题令牌，深色模式可跟随系统
- 无构建步骤、无框架、无 npm 依赖
- 可访问性：`skip-link`、`aria-label`、键盘可达的导航
- 带 Open Graph 与 `theme-color` 元信息，便于分享
