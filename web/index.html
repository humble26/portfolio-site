02 — 做法

七条能对账的工程约定

这些不是写在白板上的口号，而是能被验证的东西。每条都标了它在本工作区里的出处 —— 改了哪一处、测了哪一项，都能追回去。

  1. 01

    依赖单向向下

    入口 → 桥接 → 域逻辑 → 视图，一条线往下，不回头。域逻辑刻意不依赖 UI 框架，于是能在一个没有图形环境的地方直接跑单测。

    出处：桌面工作台的四层结构（models 层不 import 任何 UI / 框架模块）

  2. 02

    易变的外部契约收拢到一处

    易变的外部契约集中收拢到一处常量模块，每条都是「最精确 → 最宽松」的候选列表；主进程与渲染层共用的数据协议也只有一个模块。页面改版时只需要改一处。

    出处：桌面工作台的 storeproto.js（主进程与渲染层共用，被契约测试约束）

  3. 03

    把渲染层当成不可信输入

    界面提交的每个数据补丁都要先过形状、体积与白名单校验，进程间调用校验来源；AI 平台的接口地址写死在代码里，不接受设置覆盖 —— 免得密钥被转发到任意域名。

    出处：桌面工作台的 patchguard.js / security.js / ai/providers.js

  4. 04

    数据默认留在本机

    工作台、桌面宠物、抽签点名都声明不联网；截图取字走离线 OCR；转写与验证码识别都在本地推理；收藏夹工具只在你主动同步时联网。用不到联网的功能就不该有联网的权限。

    出处：桌面工作台的唯一运行依赖是离线 OCR · 桌面宠物的数据源只有本地 git 与键鼠空闲 · 音频转写的音频不出本机

  5. 05

    部署陷阱写进文档，而不是留在脑子里

    打包后可执行文件与资源目录必须同目录、单文件打包会派生子进程、未签名程序会被系统安全提示拦住 —— 这三类坑都写进了使用说明，因为「拷走一个文件打不开」这种事，用户第一次遇到时你不会在场。

    出处：抽签点名的使用说明单列一条「exe 与 _internal 必须同目录」 · Markdown 转 Word 的安装说明写了未签名提示与符号链接权限

  6. 06

    复核要能推翻自己

    全工作区检查先只读跑一遍出报告，再用独立核查逐条复算、连自己的统计错误一起公开修订；修复前先给 15 个仓库打基线标签以便回滚，修完用隔离双版本对照实测行为差异 —— 这轮自审又发现并修掉自己引入的 3 处问题。

    出处：全量代码检查报告-20260928 的修订记录 · P0 修复记录 · 修复自审与验证报告

  7. 07

    改完必须留档

    每次审查、整改、复核都留一份可对照的报告；每次归档都留说明、清单快照与来源去向映射表。下一个接手的人（很可能就是半年后的自己）应该能顺着文档把整条路走回来。

    出处：见下一节「归档与可追溯」

03 — 归档

归档与可追溯

代码会改，结论会过时，但「当时为什么这么决定」一旦丢掉就再也找不回来。 所以在这些项目之外，还有一件长期在做的事：把每一次移动、改写和结论都留成可以核对的形式。

归档约定：四件套

  1. 1 剪切移动 不是复制
  2. 2 归档说明 为什么这样归
  3. 3 清单快照 归档前的文件全貌
  4. 4 来源去向映射表 每个文件原来在哪

为什么一定要剪切而不是复制：复制会留下双份，然后两边各自修改、各自漂移，过一阵就没人说得清哪一份是准的。

  • 先定位再动手：有几项因为可执行文件被进程占用而搬不动。没有反复重试，而是逐层下钻把被占用的对象缩到四个具体文件，确认是临时占用后一次搬完。
  • 引用要跟着走：带绝对路径的脚本全部改到新位置，其中两处是本来就指错的旧缺陷，顺手修好。改完 119 个 Python 文件重新解析，0 语法错误。
  • 改完就回归：八个项目的测试套件与平台分支测试全部重跑，而不是假设「只是挪了文件不会坏」。

归档冻结

归档区里的历史报告与运行日志，里面的路径保持着当时的写法 —— 即使那些路径早已不存在。 整理时只更新可执行代码里的路径，文档与日志一个字不改：它们是当时状态的原始记录，改了就失真了。 需要复跑时，用工作集里已经同步过的现行版本。

05 — 关于

关于这些项目

这里的项目都来自我自己遇到的具体麻烦：抢不到的课、收藏了却再没打开过的视频、端到端点一遍太慢的手工流程、 宿舍里几台闲着的电脑、以及一台没有 root 权限却必须跑起来的教室电脑。习惯是先让它能用，再回头把代码审一遍、把该测的测了、把过程写下来。

技术栈是跟着问题走的，不是反过来：需要离线优先就写 Electron，只需要一扇窗口就用 tkinter， 目标是网页形态就上 pywebview，要跨机器协作就写零依赖的 Node 内核；凡是不必联网的地方就不联网。

本站项目均为本人作品。验证码识别仅作技术记录，页面不提供可运行文件。
