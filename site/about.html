这批项目的共同点

抛开功能,13 个项目在工程上守的是同几条:

  • 数据本地优先 —— 13 音频转写明确"音频不出本机",04 验证码识别模型与 wasm 全本地零上报,14 更新检查工具是只读的。数据要出本机的地方,都由用户自己决定
  • 能少装一个依赖就少装 —— 03 抽签点名、08 Markdown转Word 明确零第三方依赖,11 宿舍超算核心零依赖(仅需 Node ≥18)
  • 把坑写下来 —— 12 Token领取助手 专门解释了"双击窗口一闪就没了"是解释器缺 tcl/tk;01 桌面工作台 记录了 v1.8.2/1.8.3 空白屏的 IPC 校验根因
  • 失败要留痕 —— 12 的任何启动崩溃都写进 logs 并弹框;14 在官方源 404 时如实显示"暂无信息"而不是谎报已是最新
  • 改动留档 —— 工作区本身按 _历史快照 / 项目归档 / 交付物 分层保留历史版本,能回退对照

站点使用说明

这个站点是纯静态的,零外部依赖 —— 没有 CDN、没有外部字体、没有构建产物里的框架运行时。

  • 主题:导航右侧切换亮 / 暗 / 跟随系统三态,选择存在本地。也可用键盘 1 2 3 切换
  • 本地预览:在站点目录执行 python -m http.server 8000 后打开 http://localhost:8000
  • 改内容:所有项目数据集中在 projects.js 一个文件里。改完执行 node build-pages.js 重新生成 13 个详情页 —— 不必手改 HTML,避免文案与截图路径多处漂移

文件结构

文件作用
index.html首页:hero、精选四个、五步工作流摘要、全部项目一览
projects/index.html13 个项目总览 + 技术栈分布 + 形态与依赖表
projects/*.html13 个详情页,由 build-pages.js 从数据层生成,不要手改
how-it-works.html工作流页:05 五步全链路 + 11 算力链路,全部实拍

projects.js唯一数据源 —— 13 个项目的元数据、文案、指标、截图引用
app.js主题切换、导航、组件渲染函数、程序化示意图
styles.css设计令牌、深色模式、响应式、浏览器边框组件

screenshots/实拍截图与动图
要加新项目:在 projects.js 里加一条,填上 lede / problem / solution / features / metrics,再执行 node build-pages.js。首页、总览页、详情页会自动跟上。
